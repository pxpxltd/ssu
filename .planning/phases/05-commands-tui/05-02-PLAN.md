  **internal/cli/tui/selector.go -- the multi-select model:**

  State fields:
  ```
  type SelectorModel struct {
      title       string
      items       []SelectorItem
      cursor      int
      selected    map[int]bool     // indexes into filtered view
      allSelected map[int]bool     // indexes into full items list (persistent across filter)
      filterInput string
      filtering   bool
      showHelp    bool
      showDetail  bool
      sortMode    int              // 0=path, 1=status, 2=behind
      viewport    viewport.Model
      help        help.Model
      keys        SelectorKeyMap
      width       int
      height      int
      confirming  bool             // true when showing confirmation
      confirmed   bool
      cancelled   bool
  }
  ```

  Constructor: `NewSelectorModel(items []SelectorItem, opts SelectorOpts) SelectorModel`
  - Initialize viewport with empty content
  - Set showDetail from opts (default true per CONTEXT.md)
  - Pre-filter items using opts.FilterFn if provided
  - Set default sort (by path)

  **Init()**: return `tea.WindowSize` command to get initial dimensions.

  **Update(msg tea.Msg):**
  - `tea.WindowSizeMsg`: store width/height, resize viewport (height - header - footer), resize viewport width to half if detail visible
  - `tea.KeyMsg` when `m.confirming`:
    - "y"/"Y": set m.confirmed = true, return tea.Quit
    - "n"/"N"/esc: set m.confirming = false (back to selector)
    - Any other key: ignore
  - `tea.KeyMsg` when `m.filtering`:
    - esc: exit filter mode, clear filter
    - enter: exit filter mode, keep filter
    - backspace: remove last char from filterInput
    - Any printable char: append to filterInput, reset cursor to 0
  - `tea.KeyMsg` normal mode (match using `key.Matches`):
    - Up/k: cursor--, clamp to 0. Update viewport content to current item's DetailContent().
    - Down/j: cursor++, clamp to len(filtered)-1. Update viewport content.
    - Space: toggle selection for item at cursor. Selection tracks by ORIGINAL index (not filtered index) so selections persist across filter changes.
    - a: select all visible (filtered) items
    - A: deselect all visible items
    - enter: if any selected, set confirming=true. If none selected, do nothing (don't allow empty confirm).
    - q/esc: set cancelled=true, return tea.Quit
    - /: set filtering=true
    - ?: toggle showHelp
    - tab: toggle showDetail, resize viewport
    - s: cycle sortMode (0->1->2->0), re-sort items, reset cursor

  **View():**
  - If confirming: render confirmation view (see confirm.go below)
  - Title line at top (using TitleStyle)
  - Filter line if filtering or filterInput non-empty: "/ " + filterInput + cursor blink
  - Main content area:
    - If showDetail: split horizontally. Left pane = item list (~50% width). Separator (vertical line). Right pane = viewport with changelog.
    - If !showDetail: full-width item list.
  - Each item line: cursor indicator ("> " cyan if current, "  " otherwise) + checkbox ("[x]" green if selected, "[ ]" otherwise) + path + metadata string (branch, behind, status badge)
  - Footer: selection count ("N selected") + help line (from help.Model if showHelp, or ShortHelp if not)
  - Use lipgloss for all styling. Do NOT use fatih/color.

  **filteredItems()**: return items matching filterInput substring on Path(). Maintain mapping between filtered indices and original indices for selection tracking.

  **Selected() []*engine.SubmoduleInfo**: returns the SubmoduleInfo pointers for all selected items (used by callers after Run() completes). Iterate allSelected map, extract items by original index, type-assert to SubmoduleItem, return info pointers.

  **Cancelled() bool**: returns m.cancelled

  **internal/cli/tui/confirm.go -- confirmation view:**
  - This is NOT a separate model. It's a View helper rendered when `m.confirming == true`.
  - `renderConfirmation(m SelectorModel) string`:
    - "Selected N submodule(s) for {operation}:"
    - List each selected item path
    - Empty line
    - "Proceed? [y/N] "
  - The y/N handling is in SelectorModel.Update (above)
  - Export `SetTitle(title string)` method on SelectorModel so the caller can set the operation name used in confirmation text

  **Sort implementation:**
  - sortMode 0: sort by Path() alphabetically
  - sortMode 1: sort by PrimaryStatus() priority
  - sortMode 2: sort by CommitsBehind descending
  - After sorting, reset cursor to 0 and update viewport content

  <action>
  Create `internal/cli/tui/progress.go` with a bubbletea Model for displaying fetch progress.

  **ProgressModel struct:**
  ```
  type ProgressModel struct {
      bar       progress.Model    // bubbles/progress
      total     int
      done      int
      current   string            // currently-fetching submodule path
      failed    []string          // paths that failed
      err       error             // fatal error
      complete  bool
      result    interface{}       // holds the final result (ScanResult, UpdateResult, etc.)
      width     int
  }
  ```

  **Constructor:** `NewProgressModel(total int) ProgressModel`
  - Initialize `progress.New(progress.WithDefaultGradient())` for colorful gradient bar
  - Set total

  **ProgressMsg types (received from external goroutines via p.Send):**
  - `FetchProgressMsg{Path string, Done int, Total int, Err error}`
  - `FetchCompleteMsg{Result *engine.ScanResult, Err error}`
  - `ProcessProgressMsg{Path string, Done int, Total int, Action string, Err error}` -- for update/push streaming
  - `ProcessCompleteMsg{Result interface{}, Err error}` -- generic completion

  **Init()**: return nil (progress is driven by external messages).

  **Update(msg tea.Msg):**
  - `tea.WindowSizeMsg`: store width, update progress bar width (min(width-30, 60) to leave room for label)
  - `FetchProgressMsg`: update done, current, total. If err non-nil, append path to failed list.
  - `FetchCompleteMsg`: set complete=true, store result, return tea.Quit
  - `ProcessProgressMsg`: same as FetchProgressMsg but for update/push phase
  - `ProcessCompleteMsg`: set complete=true, store result, return tea.Quit
  - `progress.FrameMsg`: forward to bar.Update() for animation frames
  - `tea.KeyMsg` with Ctrl+C: set err to context.Canceled, return tea.Quit (cancellation handled by caller)

  **View():**
  - If total == 0: "Scanning..."
  - Calculate percentage: float64(done) / float64(total)
  - Render bar: `m.bar.ViewAs(pct)`
  - Label: " done/total" + (if current != "": " fetching currentPath")
  - If any failed: render failed count in red below bar
  - Full line: bar + label (using lipgloss MutedStyle for label)
  - Format: `[========>    ] 12/25 fetching plugins/auth`

  **Result() interface{}**: returns m.result for caller to type-assert after Run()
  **Err() error**: returns m.err
  **Complete() bool**: returns m.complete

  **Non-TTY fallback helper (used by commands, not the model itself):**
  - `PrintProgressLine(w io.Writer, done, total int, path string)` -- writes "Fetching done/total path..." for non-TTY/auto mode
