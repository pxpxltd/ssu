       - Print to `cmd.OutOrStdout()` (not fmt.Println -- enables testing):

       - `ValidArgs: []string{"bash", "zsh", "fish", "powershell"}`
       - `Args: cobra.MatchAll(cobra.ExactArgs(1), cobra.OnlyValidArgs)`
       - `RunE`: switch on `args[0]`:
         - "bash": `cmd.Root().GenBashCompletionV2(os.Stdout, true)` (true = include descriptions)
         - "zsh": `cmd.Root().GenZshCompletion(os.Stdout)`
         - "fish": `cmd.Root().GenFishCompletion(os.Stdout, true)`
         - "powershell": `cmd.Root().GenPowerShellCompletionWithDesc(os.Stdout)`

  <action>
    1. `internal/cli/compat/compat.go`: Create backwards compatibility hint system:
       - Package `compat`
       - `OldFlagHints` map: `--status` -> `ssu status`, `--push` -> `ssu push`, `--rollback` -> `ssu rollback`, `--auto` -> `ssu update --auto  (or: ssu push --auto)`, `--dry-run` -> `ssu update --dry-run  (or: ssu status)`
       - `CheckOldFlags(args []string, w io.Writer) bool`:
         - Takes args (os.Args) and a writer (for testability -- production passes os.Stderr)
         - If `len(args) < 2`, return false
         - Check ONLY `args[1]` (the first arg after binary name). This avoids false positives for `ssu update --dry-run` where `--dry-run` is a valid flag.
         - If `args[1]` matches an OldFlagHints key, print friendly hint to the writer: `Hint: Did you mean \`{suggestion}\`?` followed by `Run \`ssu help\` for the new command syntax.`
         - Return true if hint was printed, false otherwise

    2. `internal/cli/compat/compat_test.go`: Table-driven tests:
       - `TestCheckOldFlags` with cases:
         - `["ssu", "--status"]` -> detected (true), output contains "ssu status"
         - `["ssu", "--push"]` -> detected (true), output contains "ssu push"
         - `["ssu", "--rollback"]` -> detected (true)
         - `["ssu", "--auto"]` -> detected (true)
         - `["ssu", "--dry-run"]` -> detected (true)
         - `["ssu", "status"]` -> NOT detected (false) -- valid subcommand
         - `["ssu"]` -> NOT detected (false) -- no args
         - `["ssu", "update", "--dry-run"]` -> NOT detected (false) -- dry-run as flag to subcommand is fine
         - `["ssu", "--verbose"]` -> NOT detected (false) -- not an old flag
       - Use `bytes.Buffer` as the writer to capture output for assertions

    3. `internal/cli/version_test.go`:
       - `TestVersionCmd`: Create root via `NewRootCmd("1.2.3", "abc1234", "2026-02-09")`, set output to buffer, set args to `["version"]`, execute, verify output contains "1.2.3", "abc1234", "2026-02-09", and Go version string
       - `TestVersionCmdNoArgs`: Verify `ssu version extraarg` returns error (cobra.NoArgs enforcement)

    4. `internal/cli/completion_test.go`:
       - `TestCompletionBash`: Execute with args `["completion", "bash"]`, verify output contains bash-specific markers (e.g., "bash" or "complete" or "__ssu")
       - `TestCompletionZsh`: Execute with args `["completion", "zsh"]`, verify output is non-empty
       - `TestCompletionFish`: Execute with args `["completion", "fish"]`, verify output is non-empty
       - `TestCompletionInvalidShell`: Execute with args `["completion", "invalid"]`, verify error returned
       - `TestCompletionNoArgs`: Execute with args `["completion"]`, verify error returned

    5. `internal/cli/root_test.go`:
       - `TestRootCmdHelp`: Execute with `["--help"]`, verify output contains "status", "update", "push", "rollback", "backup", "version", "completion"
       - `TestRootCmdSubcommandStubs`: For each stub (status, update, push, rollback, backup), execute and verify output contains "not implemented yet"

       - On `root.Execute()` error, use `os.Exit(cli.ExitError)` instead of bare `os.Exit(1)` -- use the exit code constant.

    7. Run full test suite: `go test ./...`
