// ScanOpts configures a Scan operation.
type ScanOpts struct {
    RootDir          string         // Absolute path to the project root
    SkipList         []string       // Submodule paths to exclude
    Concurrency      int            // Max parallel goroutines (0 = runtime.NumCPU())
    BranchOpts       git.BranchDetectOpts // Passed to DetectBestBranch per submodule
    OnProgress       ProgressFunc   // Optional callback for progress events
}

// ScanResult holds the aggregate outcome of scanning all submodules.
type ScanResult struct {
    Root        *SubmoduleInfo   // Root repository info (display-only, nil if scan failed)
    Submodules  []*SubmoduleInfo // Per-submodule scan results, sorted by path
}

// SubmoduleInfo holds scan results for a single submodule (or root).
type SubmoduleInfo struct {
    Path           string                  // Relative path from root (e.g. "plugins/auth"), or "." for root
    IsRoot         bool                    // True for root repository
    Statuses       []git.SubmoduleStatus   // Compound status set (can have multiple)
    CurrentBranch  string                  // Branch name, or empty if detached
    TargetBranch   string                  // Branch detected by DetectBestBranch
    DetachedHead   bool                    // True if HEAD is detached
    CommitsBehind  int                     // Number of commits behind remote
    CommitsAhead   int                     // Number of unpushed commits
    HasChanges     bool                    // Uncommitted local changes exist
    Changelog      []string               // Incoming commit summaries (oneline format)
    Error          error                   // Non-nil if scan failed for this submodule
}

// HasStatus reports whether info has the given status in its compound set.
func (info *SubmoduleInfo) HasStatus(s git.SubmoduleStatus) bool {
    for _, st := range info.Statuses {
        if st == s {
            return true
        }
    }
    return false
}

3. Create `internal/engine/scan.go` implementing the Scan method:

```go
func (e *Engine) Scan(ctx context.Context, opts ScanOpts) (*ScanResult, error)
```

Implementation steps:
a. Apply defaults: if opts.Concurrency <= 0, use runtime.NumCPU().
b. Call `e.git.SubmodulePaths(ctx, opts.RootDir)` to enumerate submodules.
c. Filter out paths in opts.SkipList (mark them as StatusSkipped in results with no fetch).
d. **Root repository scan** (Phase 0): call `scanOne(ctx, opts.RootDir, ".", opts, true)` to get root status. Root is display-only -- it gets CurrentBranch, CommitsBehind, CommitsAhead, HasChanges but NO fetch (root fetch is included in the parallel batch with all submodules -- see step e).

Actually, per CONTEXT.md researcher recommendation: "Root repo fetch: Include in same parallel batch with IsRoot flag." So include root in the parallel fetch batch but mark it IsRoot.

e. **Parallel fetch + status detection**: Use `var g errgroup.Group` (zero value, NOT errgroup.WithContext) with `g.SetLimit(opts.Concurrency)`. For each submodule path (plus root "."):
   - IMPORTANT Go 1.21: capture loop variable `path := path`
   - Fire EventStarted progress event
   - Call `e.git.Fetch(ctx, absDir, git.FetchOpts{Prune: true})`
   - If fetch fails, record error but continue (set StatusError)
   - Call status detection: `e.scanStatus(ctx, absDir, path, opts)` (helper method)
   - Fire EventCompleted or EventFailed progress event
   - Append result to mutex-protected `[]*SubmoduleInfo` slice
   - Return nil to errgroup (never return error -- continue-on-error)
   - Use `sync.Mutex` to protect the results slice and done counter

f. After `g.Wait()`, sort results by path. Separate root from submodules.

g. **Status detection** in helper `scanStatus`:
   - Call `e.git.IsDetachedHead(ctx, dir)` -- if detached, set DetachedHead=true
   - Call `e.git.CurrentBranch(ctx, dir)` -- record CurrentBranch
   - Call `git.DetectBestBranch(ctx, e.git, dir, opts.BranchOpts)` -- record TargetBranch
   - Build remoteRef as `"origin/" + targetBranch` (or use DefaultRemote from BranchOpts)
   - Call `e.git.HasLocalChanges(ctx, dir)` -- if true, add StatusModified
   - Call `e.git.CommitsBehind(ctx, dir, "HEAD", remoteRef)` -- if > 0, add StatusPending
   - Call `e.git.CommitsAhead(ctx, dir, remoteRef)` -- if > 0, add StatusAhead
   - Call `e.git.IncomingChangelog(ctx, dir, remoteRef, 20)` -- store in Changelog
   - If no statuses added and no error, add StatusCurrent
   - For skipped submodules (in skip list), just set StatusSkipped, no git calls

h. Submodules not initialized (`e.git.IsSubmoduleInitialized(opts.RootDir, path)` returns false): set StatusMissing, skip all git operations for that path.
