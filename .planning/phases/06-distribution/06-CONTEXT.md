# Phase 6: Distribution - Context

**Gathered:** 2026-02-09

<domain>
## Phase Boundary

Users can install SSU via their preferred method on any supported platform. Covers: `go install`, GitHub releases with goreleaser, Homebrew tap, AUR package, and curl-pipe-bash install script. Does not cover CI/CD integration, plugin systems, or self-update mechanisms.

</domain>

<decisions>
## Implementation Decisions

### Platform & binary targets
- Build for 4 OS: Linux, macOS, FreeBSD, Windows
- Build for 2 architectures each: amd64, arm64 (8 total binaries)
- Static binaries with CGO_ENABLED=0
- Binary naming: `ssu_OS_ARCH` (goreleaser default underscore convention)
- Release assets: `.tar.gz` archives for Linux/macOS/FreeBSD, `.zip` for Windows
- SHA256SUMS checksum file included in every release

### Release workflow
- Semver with `v` prefix: `vX.Y.Z` (e.g., v1.0.0, v2.1.3)
- Tag push triggers GitHub Actions release: `git tag v1.0.0 && git push --tags`
- Pre-release support: tags like `v1.0.0-rc.1` create GitHub pre-release (marked as not latest)
- Changelog auto-generated by goreleaser from commit messages since last tag

### Package manager scope
- Homebrew: own tap (`pxpxltd/homebrew-tap`), auto-updated by goreleaser on release (needs GH token)
- AUR: separate AUR repo, added as a submodule in this repo
- No other package managers (Nix, Scoop, etc.) -- users on other platforms use `go install` or binary download
- `go install github.com/pxpxltd/ssu/cmd/ssu@latest` as the universal fallback

### Install script UX
- Invocation: `curl -sSL <url> | bash` (pipe-to-bash style)
- Auto-detect install location: try `/usr/local/bin` first, fall back to `~/.local/bin` if no sudo
- SHA256 checksum verification against release checksums file
- Auto-detect OS and architecture for correct binary download
- No uninstall support -- users remove the binary themselves

### Claude's Discretion

- Install script error messages and output formatting
- PKGBUILD specifics for AUR package
- Homebrew formula dependencies and test block

</decisions>
