Target 4 OS (linux, darwin, freebsd, windows) x 2 arch (amd64, arm64). ldflags: `-s -w -X main.version={{.Version}} -X main.commit={{.Commit}} -X main.date={{.Date}}`. **changelog:** Sort ascending, exclude `docs:`, `test:`, `chore:` prefixes. Group by Features (feat), Bug Fixes (fix), Others.

**homebrew_casks:** Name `ssu`, binaries `[ssu]`, repository owner `pxpxltd` name `homebrew-tap` with token `{{ .Env.HOMEBREW_TAP_TOKEN }}`. Homepage, description. `skip_upload: auto` (skips for pre-releases).

Package installs binary to `/usr/bin/ssu` and LICENSE to `/usr/share/licenses/ssu/LICENSE`. `skip_upload: auto`, `commit_msg_template: "Update to {{ .Tag }}"`.

IMPORTANT: Use `formats` (plural list) not `format` (singular string) in both archives and format_overrides. Use `homebrew_casks` not deprecated `brews`. Use `binaries` (plural) not `binary` (singular) in homebrew_casks.
