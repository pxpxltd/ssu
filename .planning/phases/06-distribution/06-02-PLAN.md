  <action>
Create `scripts/install.sh` following the golangci-lint install script pattern from the research document. The script must be wrapped in a `main()` function called at the very end to prevent partial execution when piped.

**Constants:**
- `OWNER="pxpxltd"`, `REPO="ssu"`
- `GITHUB_API="https://api.github.com/repos/${OWNER}/${REPO}"`
- `GITHUB_DOWNLOAD="https://github.com/${OWNER}/${REPO}/releases/download"`

**Functions to implement:**

`main()` -- orchestrator:
1. Call `detect_os` and `detect_arch`
2. Call `detect_install_dir`
3. Resolve version: use `VERSION` env var if set, otherwise call `get_latest_version`
4. Create temp dir with `mktemp -d`, trap cleanup on EXIT
5. Call `download` to fetch archive + checksums
6. Call `verify_checksum`
7. Call `install_binary` to extract and copy
8. Print success message with install path and version

`detect_os()`:
- `uname -s | tr '[:upper:]' '[:lower:]'`
- Map: linux->linux, darwin->darwin, freebsd->freebsd, msys*/mingw*/cygwin*->windows
- Exit 1 on unsupported OS

`detect_arch()`:
- `uname -m`
- Map: x86_64/amd64->amd64, aarch64/arm64->arm64
- Exit 1 on unsupported architecture

`detect_install_dir()`:
- If `/usr/local/bin` is writable (`[ -w /usr/local/bin ]`): use it
- Else: create `~/.local/bin` if needed, use it
- Print a note if using `~/.local/bin` that user should add it to PATH

`get_latest_version()`:
- Query `${GITHUB_API}/releases/latest`
- Extract `tag_name` using grep + sed (no jq dependency)
- Support both curl and wget
- Exit 1 if neither available

`http_download(dest, url)`:
- Try curl first: `curl -sSL -o "$dest" "$url"`
- Fall back to wget: `wget -q -O "$dest" "$url"`
- Check HTTP status / file existence, exit 1 on failure

`download(tmpdir, os, arch, version)`:
- Determine archive extension: `tar.gz` for all except windows which uses `zip`
- Build filename: `ssu_${version#v}_${os}_${arch}.${ext}` (strip leading `v` from version)
- Download archive and `checksums.txt` using `http_download`

`verify_checksum(tmpdir, filename)`:
- Read expected checksum from `checksums.txt` using grep + awk
- Compute actual checksum using `compute_sha256`
- Compare, exit 1 on mismatch with clear error message

`compute_sha256(file)`:
- Try `sha256sum` first (Linux)
- Then `shasum -a 256` (macOS)
- Then `openssl dgst -sha256` (fallback)
- Exit 1 if no SHA256 tool found

`install_binary(tmpdir, install_dir, filename)`:
- For tar.gz: `tar -xzf "$tmpdir/$filename" -C "$tmpdir" ssu`
- For zip: `unzip -o "$tmpdir/$filename" ssu -d "$tmpdir"`
- `install -m 755 "$tmpdir/ssu" "$install_dir/ssu"` (or `cp` + `chmod` as fallback)

**Script header:** `#!/usr/bin/env bash` with `set -euo pipefail`.

**Output formatting:** Use color only if stdout is a terminal. Green for success, red for errors, yellow for warnings. Keep it simple -- no fancy formatting, just clear status messages.

Make the script executable: `chmod +x scripts/install.sh`.
