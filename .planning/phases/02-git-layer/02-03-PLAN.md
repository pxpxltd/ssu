  <action>
Create `internal/git/exec.go` in package `git`.

**ExecGit struct:**
```go
type ExecGit struct {
    GitBin   string        // path to git binary, default "git"
    Timeouts TimeoutConfig
}

type TimeoutConfig struct {
    Fetch   time.Duration // default 120s
    Push    time.Duration // default 60s
    Merge   time.Duration // default 30s
    Default time.Duration // default 30s (for queries like rev-parse, branch -r)
}
```

Add a `DefaultTimeouts()` function returning the TimeoutConfig with defaults above.
Add a `NewExecGit()` function that returns `&ExecGit{Timeouts: DefaultTimeouts()}`.

**Core `run` helper (unexported):**
```go
func (g *ExecGit) run(ctx context.Context, dir string, timeout time.Duration, args ...string) (stdout, stderr string, err error)
```
- If timeout > 0, wrap ctx with `context.WithTimeout` and defer cancel.
- Use `exec.CommandContext(ctx, bin, args...)` where bin = g.GitBin or "git" if empty.
- Set `cmd.Dir = dir`
- Set `cmd.WaitDelay = 5 * time.Second` to force-kill lingering processes.
- Set `cmd.Env = append(os.Environ(), "GIT_TERMINAL_PROMPT=0")` to prevent credential hangs.
- Use `bytes.Buffer` for both Stdout and Stderr (NOT cmd.Output() -- avoids Go issue #57129).
- Call `cmd.Run()`.
- On error, wrap as `&GitError{Op: args[0], Stderr: stderr, Err: err}` (args[0] is the git subcommand like "rev-parse", "fetch", etc.).
- Return `strings.TrimSpace(stdout)`, raw stderr, and error.

**Implement ALL GitService methods. Each method follows the same pattern: call `g.run(...)`, parse output, return struct.**

Repository discovery:
- `SubmodulePaths`: Run `git config --file .gitmodules --get-regexp ^submodule\..*\.path$`. Parse each line with `strings.Fields`, take second field. Sort with `sort.Strings`. Return nil, nil for no .gitmodules or empty output.
- `IsSubmoduleInitialized`: Check if `filepath.Join(rootDir, subPath, ".git")` exists (stat, not git command). Return true if exists.

Branch and revision queries:
- `CurrentBranch`: Run `git rev-parse --abbrev-ref HEAD`. If output == "HEAD", return `BranchResult{Detached: true}`. Otherwise `BranchResult{Name: output}`. Always populate Stderr.
- `CurrentSHA`: Run `git rev-parse HEAD`. Return trimmed output.
- `IsDetachedHead`: Run `git symbolic-ref -q HEAD`. If error (exit code 1), return true (detached). If success, return false.
- `RemoteBranches`: Run `git branch -r`. Parse each line: trim whitespace, skip lines containing `->` (HEAD alias). Split on `/` to get Remote and Branch (first segment is remote, rest is branch). Return `[]RemoteBranch`.
- `CommitsBehind`: Run `git rev-list --count {localRef}..{remoteRef}`. Parse with `strconv.Atoi`. Return 0 on error (same as bash `|| echo "0"`).
- `CommitsAhead`: Run `git rev-list --count {remoteRef}..HEAD`. Parse with Atoi. Return 0 on error.
- `HasRemoteBranch`: Run `git show-ref --verify refs/remotes/{remote}/{branch}`. Return true if exit 0, false if exit non-zero.
- `SymbolicRef`: Run `git symbolic-ref {ref}`. Return trimmed output. Error if not a symbolic ref.
- `TrackingBranch`: Run `git config --get branch.{currentBranch}.remote` and `git config --get branch.{currentBranch}.merge`. First get current branch name via `git rev-parse --abbrev-ref HEAD`. If either config fails, return `TrackingInfo{Set: false}`. Parse merge ref (strip `refs/heads/` prefix). Return `TrackingInfo{Remote: remote, Branch: branch, Set: true}`.

Status queries:
- `HasLocalChanges`: Run `git status --porcelain`. Return `len(output) > 0`. This is simpler and more reliable than running separate diff commands.
- `IncomingChangelog`: Run `git log --oneline -n {limit} ..{remoteRef}`. Split output by newlines. Return the lines.

Mutating operations:
- `Fetch`: If `opts.Remote != ""`, run `git fetch {remote}`. Otherwise `git fetch --all`. If `opts.Prune`, add `--prune`. Use `g.Timeouts.Fetch` timeout.
- `Checkout`: Run `git checkout {branch}`. Use Default timeout.
- `Merge`: Run `git merge {ref}`. Use `g.Timeouts.Merge`. Parse: if error and stderr contains "CONFLICT", return `MergeResult{Conflict: true, Stderr: stderr}, err`. If success, `MergeResult{Success: true}`.
- `Push`: Check tracking branch first. If `opts.SetUpstream` or no tracking branch exists, run `git push -u {remote} {branch}` (remote defaults to "origin"). Otherwise run `git push`. Use `g.Timeouts.Push`. Return `PushResult{Remote, Branch, NewTracking: setUpstream was used}`.
- `Stash`: Run `git stash push -m "ssu-auto-stash"`. If output contains "No local changes", return `StashResult{Created: false}`. Otherwise `StashResult{Created: true}`.
- `StashPop`: Run `git stash pop`. If error, return error. Otherwise `StashResult{Created: true}`.
- `MergeAbort`: Run `git merge --abort`. Return error directly.

**Compile-time interface check:** Add `var _ GitService = (*ExecGit)(nil)` at the top of exec.go.

Imports needed: `bytes`, `context`, `fmt`, `os`, `os/exec`, `path/filepath`, `sort`, `strconv`, `strings`, `time`.

**Test helper:** Create a `setupTestRepo(t *testing.T) (dir string)` function that:
1. Creates `t.TempDir()`
2. Runs `git init` in it
3. Runs `git config user.email "test@test.com"` and `git config user.name "Test"`
4. Creates a file, `git add .`, `git commit -m "initial"`
5. Returns the directory path

Use `testing.Short()` guard: `if testing.Short() { t.Skip("skipping integration test") }` at the top of each test function. This allows `go test -short ./...` to skip these.

**Test cases:**

`TestExecGitCurrentBranch`:
- Setup: test repo (default branch is "master" or "main" depending on git config).
- Call `CurrentBranch`. Assert Name is non-empty and Detached is false.

`TestExecGitCurrentBranchDetached`:
- Setup: test repo, `git checkout --detach HEAD`.
- Call `CurrentBranch`. Assert Detached is true.

`TestExecGitCurrentSHA`:
- Setup: test repo.
- Call `CurrentSHA`. Assert result is 40-char hex string.

`TestExecGitHasLocalChanges`:
- Setup: test repo with clean working tree.
- Call `HasLocalChanges`. Assert false.
- Create a new file in the directory.
- Call `HasLocalChanges`. Assert true.

`TestExecGitRemoteBranches`:
- Setup: Create two repos -- "remote" and "local". Init remote, commit. Init local, `git remote add origin <remote-path>`, `git fetch origin`.
- Call `RemoteBranches` on local. Assert at least one RemoteBranch with Remote="origin".

`TestExecGitCommitsBehind`:
- Setup: Two repos. Remote has 3 extra commits after local cloned.
- Fetch in local, then call `CommitsBehind` with appropriate refs.
- Assert count is 3.

`TestExecGitFetch`:
- Setup: Two repos (remote + local with origin pointing to remote).
- Add a commit to remote. Call `Fetch` on local.
- Assert no error. Verify fetch brought new refs (call CommitsBehind and assert > 0).

`TestExecGitCheckout`:
- Setup: test repo with two branches.
- Create a branch `git branch test-branch`.
- Call `Checkout(ctx, dir, "test-branch")`. Assert CheckoutResult.Branch == "test-branch".
- Verify we're now on test-branch via CurrentBranch.

`TestExecGitStashAndPop`:
- Setup: test repo, modify a tracked file (don't commit).
- Call `Stash`. Assert Created == true.
- Call `HasLocalChanges`. Assert false (changes stashed).
- Call `StashPop`. Assert no error.
- Call `HasLocalChanges`. Assert true (changes restored).

`TestExecGitStashNoChanges`:
- Setup: test repo with clean working tree.
- Call `Stash`. Assert Created == false.

`TestExecGitTimeout`:
- Use a very short timeout (1 nanosecond) with a Default timeout config.
- Call any operation (e.g., `CurrentSHA`).
- Assert error is non-nil and `IsTimeout(err)` returns true.

`TestExecGitCompileTimeCheck`:
- Verify `var _ git.GitService = (*git.ExecGit)(nil)` compiles (this is also in exec.go, but having it in the test file is belt-and-suspenders).

**Test helper for cloning (setupClonedRepo):**

1. Create remote repo with setupTestRepo
2. Create local dir with t.TempDir()
