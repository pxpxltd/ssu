  <name>Task 1: GitService interface, result types, error types, and option types</name>
  <files>internal/git/git.go</files>
  <action>
Create `internal/git/git.go` in package `git`. This file defines ALL types for the git layer.

**GitService interface** with these methods (all accept `context.Context` as first param):

Repository discovery:
- `SubmodulePaths(ctx, rootDir string) ([]string, error)`
- `IsSubmoduleInitialized(rootDir, subPath string) bool` (no ctx -- local filesystem check)

Branch and revision queries:
- `CurrentBranch(ctx, dir string) (BranchResult, error)`
- `CurrentSHA(ctx, dir string) (string, error)`
- `IsDetachedHead(ctx, dir string) (bool, error)`
- `RemoteBranches(ctx, dir string) ([]RemoteBranch, error)`
- `CommitsBehind(ctx, dir, localRef, remoteRef string) (int, error)`
- `CommitsAhead(ctx, dir, remoteRef string) (int, error)`
- `HasRemoteBranch(ctx, dir, remote, branch string) (bool, error)`
- `SymbolicRef(ctx, dir, ref string) (string, error)`
- `TrackingBranch(ctx, dir string) (TrackingInfo, error)`

Status queries:
- `HasLocalChanges(ctx, dir string) (bool, error)`
- `IncomingChangelog(ctx, dir, remoteRef string, limit int) ([]string, error)`

Mutating operations:
- `Fetch(ctx, dir string, opts FetchOpts) (FetchResult, error)`
- `Checkout(ctx, dir, branch string) (CheckoutResult, error)`
- `Merge(ctx, dir, ref string) (MergeResult, error)`
- `Push(ctx, dir string, opts PushOpts) (PushResult, error)`
- `Stash(ctx, dir string) (StashResult, error)`
- `StashPop(ctx, dir string) (StashResult, error)`
- `MergeAbort(ctx, dir string) error`

**Result types** (every result has `Stderr string`):
- `BranchResult` -- Name string, Detached bool, Stderr string
- `TrackingInfo` -- Remote string, Branch string, Set bool, Stderr string
- `RemoteBranch` -- Remote string, Branch string (no Stderr -- this is a data type not a result)
- `FetchResult` -- Stderr string
- `FetchOpts` -- Remote string (empty = all remotes), Prune bool
- `CheckoutResult` -- Branch string, Stderr string
- `MergeResult` -- Success bool, Conflict bool, Stderr string
- `PushResult` -- Remote string, Branch string, NewTracking bool, Stderr string
- `PushOpts` -- Remote string, Branch string, SetUpstream bool
- `StashResult` -- Created bool (for Stash: true if stash was created; for StashPop: true if pop was applied), Stderr string

**BranchDetectOpts** (used by DetectBestBranch in branch.go):
- Override string (--branch CLI flag)
- PriorityBranches []string (default: ["develop", "master", "main"])
- DefaultRemote string (default: "origin")

**Status enum** using string constants:
- `StatusPending`, `StatusCurrent`, `StatusModified`, `StatusAhead`, `StatusConflict`, `StatusMissing`, `StatusSkipped`
- Type: `type SubmoduleStatus string`

**Error types:**
- `GitError` struct with Op string, Stderr string, Err error
- `Error() string` method -- format: "git {Op}: {Err}" with stderr appended if non-empty
- `Unwrap() error` method returning Err
- `IsTimeout(err error) bool` helper -- checks for `context.DeadlineExceeded` via `errors.Is`
- `IsConflict(err error) bool` helper -- checks for GitError with Op "merge" and "CONFLICT" in Stderr

**DefaultBranchPriority** package-level var: `[]string{"develop", "master", "main"}`

Imports needed: `context`, `errors`, `fmt`, `strings`
