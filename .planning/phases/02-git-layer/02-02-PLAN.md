  <name>Task 1: DetectBestBranch function implementing the 5-level priority chain</name>
  <files>internal/git/branch.go</files>
  <action>
Create `internal/git/branch.go` in package `git`.

**Function:** `DetectBestBranch(ctx context.Context, svc GitService, dir string, opts BranchDetectOpts) (string, error)`

This is a standalone function, NOT a method on any struct. It calls GitService methods to make decisions. The algorithm ports the bash `detect_best_branch()` function (lines 535-590 of legacy/ssu) faithfully.

**Priority chain (order is critical -- do NOT rearrange):**

1. **Override:** If `opts.Override != ""`, return it immediately. This is the `--branch` CLI flag.

2. **Feature branch preservation:** Call `svc.CurrentBranch(ctx, dir)`.
   - If error, wrap and return (can't detect without knowing current branch).
   - If detached (`result.Detached == true`), skip to step 3.
   - If current branch name IS in `opts.PriorityBranches`, skip to step 3 (it's not a feature branch).
   - If current branch name is NOT in `opts.PriorityBranches`:
     - Determine the remote to check: use `opts.DefaultRemote` (default "origin").
     - Call `svc.HasRemoteBranch(ctx, dir, remote, currentBranch)`.
     - If error, treat as "no remote" and fall through (do NOT hard fail).
     - If true (remote exists for this feature branch), return the current branch name. Feature branch preserved.

3. **Priority chain:** For each branch in `opts.PriorityBranches` (default: ["develop", "master", "main"]):
   - Call `svc.RemoteBranches(ctx, dir)` ONCE (cache the result, don't call per branch).
   - If error fetching remote branches, set a flag and skip to step 4.
   - Check if any RemoteBranch in the list matches this priority branch name.
   - When comparing, match against ANY remote (not just opts.DefaultRemote) -- if `upstream/develop` exists, that counts.
   - First match wins -- return that branch name.

4. **Remote HEAD fallback:** Call `svc.SymbolicRef(ctx, dir, "refs/remotes/"+opts.DefaultRemote+"/HEAD")`.
   - If error, skip to step 5.
   - Parse the result: if it looks like `refs/remotes/origin/develop`, extract "develop".
   - Return the extracted branch name.

5. **Final fallback:** If remote branches were fetched in step 3 and the list is non-empty, return the first remote branch's name. Otherwise return "master" as absolute fallback.

**Helper function:** `isInList(name string, list []string) bool` -- simple linear search. Unexported.

**Default handling for BranchDetectOpts:**
- If `opts.PriorityBranches` is nil or empty, use `DefaultBranchPriority` from git.go.
- If `opts.DefaultRemote` is empty, use "origin".

Apply these defaults at the top of DetectBestBranch, not in the caller.

<task type="auto">
  <name>Task 2: Comprehensive table-driven tests for branch detection</name>
  <files>internal/git/branch_test.go</files>
  <action>
Create `internal/git/branch_test.go` in package `git_test`.

Use table-driven tests with `t.Run` subtests. Each test case configures a MockGitService with specific Fn overrides to simulate a branch scenario, then calls `git.DetectBestBranch` and asserts the returned branch.

**Test cases for `TestDetectBestBranch`:**

1. **"override takes priority"** -- opts.Override = "custom-branch", mock has develop on remote. Expect: "custom-branch".

2. **"feature branch preserved when remote exists"** -- CurrentBranch returns "feature/xyz" (not in priority list), HasRemoteBranch returns true for "feature/xyz". Expect: "feature/xyz".

3. **"feature branch without remote falls to priority chain"** -- CurrentBranch returns "feature/xyz", HasRemoteBranch returns false. RemoteBranches includes "develop". Expect: "develop".

4. **"priority chain: develop wins over master"** -- CurrentBranch returns "develop" (in priority list, so not a feature branch). RemoteBranches includes both "develop" and "master". Expect: "develop".

5. **"priority chain: master when no develop"** -- CurrentBranch returns "master". RemoteBranches includes "master" and "main" but NOT "develop". Expect: "master".

6. **"priority chain: main as last priority"** -- CurrentBranch returns "main". RemoteBranches includes only "main". Expect: "main".

7. **"detached HEAD skips feature check, uses priority chain"** -- CurrentBranch returns Detached=true. RemoteBranches includes "develop". Expect: "develop".

8. **"remote HEAD fallback when no priority branches match"** -- CurrentBranch returns detached. RemoteBranches returns empty or error. SymbolicRef returns "refs/remotes/origin/staging". Expect: "staging".

9. **"absolute fallback to master"** -- CurrentBranch returns detached. RemoteBranches returns empty. SymbolicRef returns error. Expect: "master".

10. **"first remote branch as fallback"** -- CurrentBranch returns detached. RemoteBranches returns [origin/release-1.0]. SymbolicRef returns error. No priority branches match. Expect: "release-1.0".

11. **"custom priority branches"** -- opts.PriorityBranches = ["staging", "production"]. CurrentBranch returns "staging". RemoteBranches includes "staging". Expect: "staging".

12. **"feature branch check uses default remote"** -- opts.DefaultRemote = "upstream". CurrentBranch returns "feature/foo". HasRemoteBranch called with remote="upstream". Returns true. Expect: "feature/foo".

13. **"HasRemoteBranch error is non-fatal"** -- CurrentBranch returns "feature/xyz". HasRemoteBranch returns error. Should fall through to priority chain, not fail.

14. **"RemoteBranches error is non-fatal"** -- All remote queries fail. Should fall through to SymbolicRef or final fallback.

For each test case, create a `MockGitService` with only the necessary Fn fields set. Rely on defaults for unneeded methods.

Assert both the returned branch string and that error is nil (or non-nil for error cases).
