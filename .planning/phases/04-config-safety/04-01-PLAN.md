    Add Viper v1.20.1 dependency: `go get github.com/spf13/viper@v1.20.1`

    Create `internal/config/config.go`:
    - Config struct with nested GitConfig, BranchConfig, BackupConfig, LogConfig using `mapstructure` tags
    - GitConfig: ParallelJobs (int), Skip ([]string), FailFast (bool)
    - BranchConfig: Priority ([]string), Override (string)
    - BackupConfig: Enabled (bool), MaxBackups (int)
    - LogConfig: MaxSizeMB (int), MaxBackups (int)
    - `Load(projectRoot string) (*Config, *AnnotatedConfig, error)` function:
      1. Create `viper.New()` instance (NOT global viper)
      2. Set defaults: git.parallel_jobs=8, git.fail_fast=false, branches.priority=["develop","master","main"], backup.enabled=true, backup.max_backups=10, log.max_size_mb=10, log.max_backups=5
      3. Read global config: ~/.ssu/config.yaml (skip if not found, error if malformed)
      4. Read project config: {projectRoot}/.ssu.yaml, merge via MergeConfigMap (skip if not found)
      5. Env var binding: SetEnvPrefix("SSU"), SetEnvKeyReplacer(strings.NewReplacer(".", "_")), AutomaticEnv()
      6. Legacy env var: check os.Getenv("PARALLEL_JOBS"), apply ONLY if SSU_GIT_PARALLEL_JOBS is not set
      7. Unmarshal into Config struct
      8. Build AnnotatedConfig tracking which layer set each value
    - `Defaults() Config` function that returns the default config (useful for tests and config show)
    - All YAML keys must be lowercase snake_case to avoid Viper key lowercasing pitfall

    Create `internal/config/source.go`:
    - `type Source string` with constants: SourceDefault, SourceGlobal, SourceProject, SourceEnv, SourceFlag
    - `type AnnotatedValue struct { Value any; Source Source }`
    - `type AnnotatedConfig struct` with map[string]AnnotatedValue for all config keys (flat dot-notation keys like "git.parallel_jobs")
    - `Get(key string) AnnotatedValue` method
    - During Load(), track sources: after defaults all are SourceDefault, after global merge update changed keys to SourceGlobal, after project merge update to SourceProject, after env check update to SourceEnv
    - Flag overrides are tracked later in PersistentPreRunE (SourceFlag)

    Create `internal/config/context.go`:
    - `type ctxKey struct{}`
    - `func WithConfig(ctx context.Context, cfg *Config) context.Context`
    - `func FromContext(ctx context.Context) *Config`
    - Also store AnnotatedConfig: `type annotatedCtxKey struct{}`
    - `func WithAnnotated(ctx context.Context, ac *AnnotatedConfig) context.Context`
    - `func AnnotatedFromContext(ctx context.Context) *AnnotatedConfig`

    - Test defaults: Load with no files returns correct defaults
    - Test global config: create temp dir with config.yaml, verify values override defaults
    - Test project config: create temp dir with .ssu.yaml, verify project overrides global
    - Test layering: both global and project exist, project wins for overlapping keys
    - Test env var: set SSU_GIT_PARALLEL_JOBS, verify it overrides file config
    - Test legacy env var: set PARALLEL_JOBS (without SSU prefix), verify it works
    - Test legacy env var priority: set both PARALLEL_JOBS and SSU_GIT_PARALLEL_JOBS, SSU_ wins
    - Test source annotations: verify AnnotatedConfig tracks correct sources
    - Use t.TempDir() for temp directories, t.Setenv() for env vars

    - Add config command to root.AddCommand() in root.go (replace nothing -- this is a NEW command)
