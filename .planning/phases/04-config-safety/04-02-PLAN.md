<objective>
Implement the backup/rollback subsystem: atomic JSON backup creation, bash-era format compatibility, backup management commands (list/clean), and rollback with SHA+branch restore.

Purpose: Backup/rollback is SSU's safety net. Before any destructive update operation, a backup is created atomically. If something goes wrong, rollback restores submodules to exact prior state. This plan implements the complete lifecycle from creation through management to restoration.

Output: `internal/backup/` package with all backup operations; wired `ssu backup list`, `ssu backup clean`, and `ssu rollback` commands.
</objective>

    - Write data, call Sync(), Close(), then os.Rename to final path

    Create `internal/backup/backup.go`:
    - Type definitions:
      - `type SubmoduleState struct { SHA string json:"sha"; Branch string json:"branch" }`
      - `type Backup struct { Version int json:"version"; Timestamp string json:"timestamp"; Submodules map[string]SubmoduleState json:"submodules" }`
    - `func BackupDir(projectName string) string` -- returns filepath.Join(home, ".ssu", projectName, "backups")
    - `func ProjectName(projectRoot string) string` -- returns filepath.Base(projectRoot) (matches bash behavior)
    - `func Create(backupDir string, submodules map[string]SubmoduleState) (string, error)`:
      1. Ensure backupDir exists (os.MkdirAll)
      2. Build Backup struct with Version=2, Timestamp=time.Now().Format(time.RFC3339), submodules map
      3. Marshal to JSON with json.MarshalIndent (readable)
      4. Generate filename: `backup-YYYYMMDD-HHMMSS.json` (no dot prefix -- Go-era format)
      5. Call AtomicWrite with the full path
      6. Return the filename (not full path)
    - `func Read(path string) (*Backup, error)`:
      1. Read file contents
      2. Try unmarshal as Go-era format (has Version field)
      3. If Version==0 or missing, delegate to ReadBashEra
      4. Return normalized Backup struct
    - `func List(backupDir string) ([]BackupInfo, error)`:
      1. Read backupDir directory entries
      2. Also read parent directory (backupDir/..) for bash-era backups (.submodule-backup-*.json)
      3. Parse timestamp from filename for each backup
      4. Sort by timestamp descending (newest first)
      5. Return slice of BackupInfo (Filename, Path, Timestamp, IsBashEra bool)
    - `type BackupInfo struct { Filename string; Path string; Timestamp time.Time; IsBashEra bool }`
    - `func Clean(backupDir string, keep string) (removed int, err error)`:
      1. Call ParseKeepArg to determine mode and value
      2. Call List to get all backups sorted by time
      3. If mode=="count": keep the N newest, remove the rest
      4. If mode=="time": keep backups newer than N days, remove the rest
      5. Only remove Go-era backups (do NOT auto-delete bash-era backups -- they're in a different dir)
      6. Return count of removed files
    - `func ParseKeepArg(arg string) (mode string, value int, err error)`:
      1. If suffix is "d": parse int prefix as days, return ("time", days, nil)
      2. Otherwise: parse as int, return ("count", count, nil)
      3. Error if non-positive or unparseable

    Create `internal/backup/compat.go`:
    - `func ReadBashEra(data []byte) (*Backup, error)`:
      1. Unmarshal JSON into a struct matching bash format: `{ "timestamp": "...", "submodules": {...} }` (no "version" field)
      2. Convert to Backup struct with Version=1
      3. Return normalized Backup
    - `func IsBashEraFilename(name string) bool`:
      1. Match pattern: `.submodule-backup-YYYYMMDD-HHMMSS.json` (starts with dot)

    Create `internal/backup/rollback.go`:
    - `type RollbackOpts struct { BackupPath string; ProjectRoot string; BackupDir string; DryRun bool }`
    - `type RollbackResult struct { SafetyBackupPath string; RestoredCount int; Submodules []RestoredSubmodule }`
    - `type RestoredSubmodule struct { Path string; SHA string; Branch string; Error error }`
    - `func Rollback(opts RollbackOpts, gitCheckout func(dir, branch string) error, gitResetHard func(dir, sha string) error) (*RollbackResult, error)`:
      1. Read the backup file via Read()
      2. If not DryRun: create a safety backup of current state first (calls Create with current submodule states)
         - Note: getting current state requires git calls, so accept a `getCurrentStates func(projectRoot string, paths []string) (map[string]SubmoduleState, error)` parameter
      3. For each submodule in the backup:
         a. Checkout the branch (avoids detached HEAD)
         b. Reset to the exact SHA
         c. If branch checkout fails (branch deleted): create the branch from SHA, then checkout
         d. Record result (success or error per submodule)
      4. All-or-nothing: if ANY submodule fails, log error but continue with remaining (user decided all-or-nothing means "attempt all" not "abort on first failure" -- the safety backup is the undo mechanism)
      5. Return RollbackResult with safety backup path and per-submodule results
    - IMPORTANT: Rollback accepts function parameters for git operations instead of importing the git package directly. This keeps backup package independent from git package (they'll be wired together in Phase 5 commands). The function signatures match what git.GitService provides.
