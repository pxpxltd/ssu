    Add lumberjack dependency: `go get gopkg.in/natefinch/lumberjack.v2`

    Create `internal/logging/handler.go`:
    - `type BracketHandler struct` implementing slog.Handler:
      - Fields: w io.Writer, level slog.Leveler, mu sync.Mutex
    - `func NewBracketHandler(w io.Writer, level slog.Level) *BracketHandler`
    - `func (h *BracketHandler) Enabled(_ context.Context, level slog.Level) bool` -- returns level >= h.level.Level()
    - `func (h *BracketHandler) Handle(_ context.Context, r slog.Record) error`:
      - Lock mutex
      - Format: `[2006-01-02 15:04:05] [LEVEL] message\n`
      - Use r.Time.Format("2006-01-02 15:04:05") for timestamp
      - Use strings.ToUpper(r.Level.String()) for level -- this gives "INFO", "WARN", "ERROR", "DEBUG"
      - Map slog level strings: slog uses "WARN" not "WARNING". Keep "WARN" for consistency with slog, but if bash compatibility requires "WARNING", map it.
      - Actually, bash uses "INFO", "SUCCESS", "ERROR", "WARN" -- slog levels are DEBUG, INFO, WARN, ERROR. Map SUCCESS to INFO level with a note. Keep the standard slog levels.
      - Write formatted string to h.w
    - `func (h *BracketHandler) WithAttrs(attrs []slog.Attr) slog.Handler` -- return h (SSU uses simple messages, no structured attrs for file logs)
    - `func (h *BracketHandler) WithGroup(name string) slog.Handler` -- return h
    - This handler is ~35 lines of code total

    Create `internal/logging/logging.go`:
    - `type MultiHandler struct` implementing slog.Handler:
      - Holds a slice of slog.Handler
      - Enabled: returns true if ANY handler is enabled
      - Handle: fans out to all enabled handlers
      - WithAttrs/WithGroup: returns new MultiHandler with updated handlers
    - `func InitLogger(logDir string, verbose bool, maxSizeMB, maxBackups int) (*slog.Logger, error)`:
      1. Create log directory: os.MkdirAll(logDir, 0o755)
      2. Create lumberjack writer:
         ```
         &lumberjack.Logger{
             Filename:   filepath.Join(logDir, "submodule-update.log"),
             MaxSize:    maxSizeMB,
             MaxBackups: maxBackups,
             LocalTime:  true,
         }
         ```
      3. Create file handler: NewBracketHandler(lumberjackWriter, slog.LevelInfo)
      4. If verbose:
         - Create stderr handler: NewBracketHandler(os.Stderr, slog.LevelDebug)
         - Combine with MultiHandler: [fileHandler, stderrHandler]
      5. If not verbose:
         - Just use fileHandler
      6. Return slog.New(handler), nil
    - `func LogDir(projectName string) string` -- returns filepath.Join(home, ".ssu", projectName, "logs")

    Create `internal/logging/logging_test.go`:
    - Test BracketHandler format: write a log record, verify output matches `[timestamp] [INFO] message\n`
    - Test BracketHandler levels: DEBUG record not emitted when level is INFO
    - Test BracketHandler WARN level: verify it outputs "[WARN]" not "[WARNING]"
    - Test InitLogger creates log directory and file
    - Test InitLogger verbose mode: verify both file and stderr get output (use bytes.Buffer as stderr mock)
    - Test InitLogger non-verbose: verify only file gets output
    - Test MultiHandler: verify fan-out to multiple handlers
    - Use t.TempDir() for log directories
    - For testing, don't use lumberjack directly -- use bytes.Buffer to verify handler output format, then a separate test verifies InitLogger creates the file (integration-style)
