# Phase 5.1 Plan 01: Embedded Commands and Install Logic Summary

**Claude Code slash command files embedded in Go binary with install extraction to ~/.claude/commands/ssu/**

## What Was Built

Created the `internal/claude/` package containing:

1. **Three slash command markdown files** (`commands/status.md`, `commands/update.md`, `commands/push.md`) with YAML frontmatter (description + allowed-tools). Update and push commands include mandatory `--auto` flag for non-TTY Claude Code environment.

2. **CLAUDE.md snippet** (`snippet.md`) -- a concise reference block users paste into their project's CLAUDE.md to teach Claude Code about SSU. Under 20 lines, covers available commands, when to use SSU vs raw git, and important notes about `--auto` and backups.

3. **Embed directives** (`embed.go`) -- `CommandsFS` (embed.FS for command files) and `SnippetContent` (string for snippet). Both resolve at compile time.

4. **Install logic** (`install.go`) -- `InstallCommands(force)` writes to `~/.claude/commands/ssu/`, `InstallCommandsTo(dir, force)` for testability. Returns `InstallResult` with Installed/Skipped/Dir. Identical files silently skipped. Differing files error without force, overwrite with force.

5. **Six tests** (`install_test.go`) covering fresh install, skip-identical, error-on-different, force-overwrite, nested directory creation, and snippet embed verification.
