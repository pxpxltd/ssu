  <action>
Create `internal/cli/claude.go` following the established one-file-per-command pattern (see config.go for reference: parent command with subcommands).

1. `NewClaudeCmd()` -- parent command:
   - `Use: "claude"`, `Short: "Claude Code integration"`
   - `Long`: Explains that this command installs slash commands and generates CLAUDE.md snippets for Claude Code integration
   - `RunE`: returns `cmd.Help()` (same pattern as NewConfigCmd)
   - Adds two subcommands: `NewClaudeInstallCmd()` and `NewClaudeSnippetCmd()`

2. `NewClaudeInstallCmd()` -- install subcommand:
   - `Use: "install"`, `Short: "Install slash commands for Claude Code"`
   - `Long`: Explains what gets installed, where (`~/.claude/commands/ssu/`), and the --force flag
   - Local `--force` bool flag (default false)
   - `Args: cobra.NoArgs`
   - `RunE`:
     a. Get force flag value
     b. Call `claude.InstallCommands(force)` (import as `claudepkg "github.com/pxpxltd/ssu/internal/claude"` to avoid name collision with the command variable)
     c. Use `output.NewPrinter(cmd.OutOrStdout())` for output
     d. On success, print each installed file with a green checkmark: `p.Success("Installed %s", name)`
     e. Print each skipped file with info: `p.Info("Skipped %s (identical)", name)`
     f. Print summary: "Installed N command(s) to <dir>"
     g. Print hint: "Commands available: /ssu:status, /ssu:update, /ssu:push"
     h. On error, wrap and return

3. `NewClaudeSnippetCmd()` -- snippet subcommand:
   - `Use: "snippet"`, `Short: "Print CLAUDE.md snippet for SSU"`
   - `Long`: Explains that this prints a markdown block to paste into CLAUDE.md
   - `Args: cobra.NoArgs`
   - `RunE`: `fmt.Fprint(cmd.OutOrStdout(), claudepkg.SnippetContent)` and return nil

Import the claude package with an alias to avoid naming collision:
```go
import (
    claudepkg "github.com/pxpxltd/ssu/internal/claude"
)
```

Follow these existing patterns from the codebase:
- `output.NewPrinter(cmd.OutOrStdout())` for formatted output (see config.go)
- Printer methods: `p.Success()`, `p.Info()`, `p.Error()` -- check what's available on the Printer struct in `internal/cli/output/printer.go`
- If Printer doesn't have Success/Info methods, use `fmt.Fprintf` with `output.Green`, `output.Cyan`, `output.Symbols.Check` etc. from the output package
