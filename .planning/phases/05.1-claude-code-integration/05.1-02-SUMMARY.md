# Phase 5.1 Plan 02: CLI Commands Summary

Wire the internal/claude package to SSU's cobra CLI with install and snippet subcommands.

## One-liner

Cobra commands for `ssu claude install` (slash command files) and `ssu claude snippet` (CLAUDE.md block).

## What Was Done

### Task 1: Create claude.go cobra commands (7b55635)

Created `internal/cli/claude.go` following the one-file-per-command pattern:

- `NewClaudeCmd()` -- parent command with help-only RunE
- `NewClaudeInstallCmd()` -- calls `claude.InstallCommands(force)`, reports installed/skipped files with Printer
- `NewClaudeSnippetCmd()` -- prints `claude.SnippetContent` to stdout
- Used `claudepkg` import alias to avoid naming collision with cobra command variables

### Task 2: Register claude command on root (6c19555)

- Added `NewClaudeCmd()` to `root.AddCommand()` in root.go after `NewCompletionCmd()`
- Verified end-to-end: `ssu claude --help`, `ssu claude install --help`, `ssu claude snippet`
- Full test suite passes with zero regressions
